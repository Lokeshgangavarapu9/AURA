# Avatar Models Directory

Place your 3D VRM avatar model file here:

`companion.vrm`

Path: `/public/models/companion.vrm`

Once you open this project in VS Code and add your `companion.vrm` file to this folder, the `AvatarViewer` component will automatically load and render your custom VRM avatar with full support for:
- Facial expressions (Happy, Relaxed, Surprised, etc.)
- Automatic blinking
- Lip sync while speaking
- Eye contact & face tracking
- Glowing stage & particle effects
